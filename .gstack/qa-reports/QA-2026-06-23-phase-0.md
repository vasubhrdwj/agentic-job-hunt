## Blocking findings

### P0 — Resume content can be exported through tracing

Production enables Phoenix/OpenInference tracing. The Google GenAI prompt
contains a resume excerpt, and input redaction is not configured. Resume
content may therefore leave the application through generated tracing spans.
Phase 1 moves trace redaction, storage encryption, ownership capability,
retention, and deletion ahead of queue persistence.

### P0 — Long-running synchronous request

`POST /api/hunt` runs the complete pipeline before responding. A real run takes
roughly 60–120 seconds, which is vulnerable to browser, proxy, platform, and
deployment interruption. Phase 2 replaces this with persisted queue state,
worker execution, and frontend polling.

### P0 — Ephemeral production data

The deployment configuration stores SQLite at `/tmp/outcomes.db`. Runs and
outcomes may disappear after a restart or deploy. Phase 3 adds durable
production storage and a separate worker topology.

### P0 — No ownership or abuse boundary

Anyone who knows a run ID can read it or append outcomes, and anyone who can
reach the API can consume provider-backed work. Phase 1 adds a capability
boundary; Phase 4 adds authenticated ownership and rate/concurrency controls.

### P0 — Resume privacy lifecycle is incomplete

Resume text is sent through the processing pipeline, but encryption, retention,
deletion, and log/trace-redaction guarantees are not yet enforced in code.
Phase 1 implements and tests these controls before queue persistence.

### P1 — Live supply misses the target gate

The strict live run on 2026-06-23 returned two qualifying first-party,
full-time junior roles in India rather than the required three. The system
correctly refused to pad the result, but `REBUILD_PLAN_V2.md` is not complete.
Phase 5 must satisfy the original gate or obtain explicit approval for a
requirement change.

### P1 — Deployment proof is incomplete

The production container and complete web/worker/database staging topology have
not yet passed exhaustive end-to-end QA. Phase 6 owns this release gate.
